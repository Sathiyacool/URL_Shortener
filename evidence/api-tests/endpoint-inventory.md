# API endpoint inventory

Inspected from the Spring controller mappings and rechecked against the live default-profile OpenAPI document on 2026-10-17. The OpenAPI document has 17 application operations. Springdoc and Actuator add the generated endpoints listed below. This inventory does not infer undocumented routes.

**Local profile:** no authentication is configured; routes were exercised against loopback. **Production profile:** orchestration, scenarios, approvals, metrics, URL analytics, and non-health Actuator routes require `SCOPE_agentic.operator`; URL creation, redirects, and health are public. Swagger/OpenAPI are disabled and denied in production.

## Authentication evidence boundary

The local default-profile HTTP run intentionally has no authentication. The production-profile outcomes are verified by 7 focused MockMvc tests (4 `ProductionAuthorizationBoundaryTest`, 2 `ProductionSecurityIntegrationTest`, 1 `ProductionFailClosedTest`): synthetic JWTs exercise anonymous `401`, insufficient-scope `403`, operator access, public health, and fail-closed configuration. Screenshots 13–15 in `security/` are **screenshots of Surefire text reports**, not live HTTP requests or real identity-provider verification. Live production-profile requests are blocked here because no test PostgreSQL server or OIDC identity provider is configured. See [../../docs/HARDENING_REVIEW.md](../../docs/HARDENING_REVIEW.md).
